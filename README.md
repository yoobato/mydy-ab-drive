# Drivebook Alberta

A bilingual, visual driving guide for people who are new to Alberta roads.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The static site is written to `dist/`. It can be served by Caddy or Nginx on AWS Lightsail.

## Content and attribution

The guide is based on official Alberta and municipal sources. It contains information licensed under the Open Government Licence – Alberta. This project is an unofficial educational resource and is not endorsed by the Government of Alberta.
